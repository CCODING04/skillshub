# 规则与反例

每条规则 = 触发条件 + 执行动作 + 可检验的判断线 + 明确禁止。文档只写「必须怎样」，不写「某次怎样」。

本文件是规则索引；具体参数与版式细则见 `layout-spec.md`（排版与六槽位）、`themes.md`（主题与配色派生）、`figure-workflow.md`（插图）、`feasibility.md`（调研）。

## S0 调研与决策

### G1 调研先于执行

- **触发**：源未收录、接口/平台规则有时效性、可行路径 ≥2、用户描述含糊。
- **执行**：只读探测（`probe_source.py`）→ 检索当下做法（带来源与日期）→ 写 `feasibility.json`（≥2 条路径 + 代价 + 风险 + 回退 + 置信度）→ 交人拍板。
- **判断线**：`feasibility.json` 至少两条候选；每条有工具、凭据、成本、风险、回退；`status` 为 `draft-not-executed` 时不得声称已跑通。
- **禁止**：凭先验猜路径；用「先做出来再说」代替调研；把检索摘要当亲自验证；调研阶段下载正文、登录或消耗积分。

### G2 决定必须由人拍板

- **触发**：涉及主题、立场、口径、篇幅、图型、交付形态、排版主题、成本取舍、验收标准。
- **执行**：给选项 + 依据 + 推荐，停下来等人选；选定结果写入 `content.json.decisions`。
- **判断线**：每个偏好项都有用户的明确选择；后续阶段不得擅自改写 `decisions`。
- **禁止**：默认替用户选；把「检测到的客观数据」当成「用户的选择」；用推荐语气替人拍板。

### G3 问之前先把依据做完

- **触发**：需要向用户提问（未知源、成本、口径、主题）。
- **执行**：先完成只读探测、环境检测（`detect_options.py`）、必要检索，算出各路径代价，再发问。
- **判断线**：问题里带探测结果、候选方案、成本与推荐；用户只需要做选择，不需要自己查资料。
- **禁止**：空手提问；让用户替你调研；信息不足时一边猜一边问。

### G4 只附原作者名，不造署名组件

- **触发**：每次成稿的 S0。
- **执行**：我们是把别的形式的内容转成公众号文章，**直接附上原作者名称**（写在 `source.author`，随文末来源说明呈现）。来源里找到就不额外询问；找不到时，S0-B 才询问「是否需要补 `author` 字段」。不生成独立署名区、不写一句话简介。
- **判断线**：成稿 0 个 `{{作者名}}` / `{{一句话简介}}` 之类占位符；原作者要么真实存在，要么字段缺失且已在 S0-B 问过。
- **禁止**：自行编造作者、身份或简介；把整理者当作者；生成占位符。

## S1 采集

### G5 先探测后下载

- **触发**：任何音视频或大文件。
- **执行**：先取 HEAD、媒体清单、HLS 主列表，确认时长、码率、音轨、字幕，再按 S0 选定清晰度下载。
- **判断线**：下载前已有码率/体积/音轨数据；只做转写时优先音轨而非画质。
- **禁止**：未测就拉 GB 级文件；为转写多花数倍体积。

### G6 失败分域定位，不重复试同一条路

- **触发**：请求失败、502、超时。
- **执行**：分别测直连、同域其他子域、协议、域名变体、备用 API，把「网络问题」缩到具体域名或通道。
- **判断线**：每类失败都有一次独立测试记录；换通道/换路径的依据可复述。
- **禁止**：对同一路径反复重试；把「我这里不通」说成「该源不可用」。

### G7 同源结果不能互称独立信源

- **触发**：用平台字幕、转写、官方页面做多信源校对。
- **执行**：先做两两归一化 CER；一致度高时合并为同一来源的不同版本。
- **判断线**：`caveats` 里写明校对材料与同源判断；不得把同源一致度说成准确率。
- **禁止**：把同源字幕标成「第二信源」；用「一致度 98%」暗示准确率。

## S2 规范化

### G8 IR 是唯一边界

- **触发**：任何渠道进入排版前。
- **执行**：把内容写成 `content.json`（`assets/content_ir.example.json` 结构）；渠道差异只存在于适配器。
- **判断线**：`title / lead / sections[] / sources / caveats / decisions` 齐备；可选字段缺省即不渲染。
- **禁止**：让渲染层读渠道私有格式；在排版阶段改口径。

### G9 读者说明与内部过程分离

- **触发**：写来源说明与整理过程。
- **执行**：`reader_notes` 只写外部读者需要的精简来源；`process_appendix` 只进 Markdown。
- **判断线**：HTML 文末无取流参数、校验命令、口径变更细节。
- **禁止**：把内部施工日志塞进正文文末。

## S3 配图

### G10 默认代码画图，不用生图工具

- **触发**：所有插图；用户明确要求 AI 插画时另行处理。
- **执行**：默认一律用 `assets/figure_types/` 的 HTML/CSS 版式 + DOM 渲染中文，`render_figures.py` 2 倍输出 PNG。**除用户明确指定 AI 插画外，不调用生图工具**；例外时先说明积分消耗并取得同意。
- **判断线**：默认流程 0 次生图调用；走 AI 插画时 `decisions` 有积分说明与用户同意记录；中文无乱码；图片无外链字体。
- **禁止**：未经同意调用生图模型；用生图模型渲染中文标注；用外部字体或远程 CSS。

### G11 先定问题，再选图型

- **触发**：每张图开工前。
- **执行**：写清这张图唯一要回答的问题，再从封面/对比/流程/清单/路线图中选型。
- **判断线**：图注是一句「这张图在回答什么」，不是「示意图」；图内事实与关系均可在原文找到。
- **禁止**：先挑模板再塞内容；图注复述标题；把讲者个人选择画成标准答案。

### G12 逐张看图才算完成

- **触发**：每张图渲染后。
- **执行**：逐张检查文字完整、无截断/乱码、卡片不溢出、副标题不被压、底部结论可见；改完重渲染复看。
- **判断线**：每张图都过一遍检查清单；有返工时记录改了什么。
- **禁止**：「差不多就行」直接入稿；只看一张就批量交付。

### G12b 两图之间必须有正文（S22）

- **触发**：稿子里出现第二张图，或两张图在 IR 里相邻。
- **执行**：在相邻两张图之间写一段正文（≥40 中文字），承担三件事：说清上一张图在看什么、给出下一张图要回答的问题、把两张图的关系接上。图注不算过渡——图注是标签，不是叙述。
- **判断线**：`validate_article.py` 的 S22 通过；把两张图连着的区域单独截图看，视线不会「撞」在一起。
- **禁止**：靠图注凑过渡；为塞文字硬写一句废话；两张图信息重复时用文字掩盖，而不是删掉重复的那张。

## S4 排版

### G13 全内联，白名单标签

- **触发**：生成 HTML。
- **执行**：所有样式写成 `style` 属性；图片 base64 内嵌 + 独立 PNG 双轨。
- **判断线**：`<style` = 0、`class=` = 0、外链资源 = 0；标签限于 `div/p/img/strong/h1/h2/br/blockquote/span/table/tr/td`；禁用 `section/figure/figcaption/script/iframe`。
- **禁止**：样式表、class、外链字体、`position:fixed`。

### G14 一套文章只用一套主题

- **触发**：选主题与排版。
- **执行**：从六套内置主题选一套，或按骨架派生一套；全篇章节头、卡片、代码框、CTA 全部用同一套。
- **判断线**：章节头骨架全篇一致；不出现两种编号样式；同一份稿只引用一个 `theme.json`。
- **禁止**：混搭两套主题；单个章节套巨型外框或异色背景；用「局部美化」破坏全篇统一。

### G15 代码框六槽位按主题取值

- **触发**：IR 含 `code` 块。
- **执行**：底 / 字 / 关键字 / 注释 / 边框 / 左条按主题取值；`keyword` 画在浅底，`label` 画在代码头，分开派生。
- **判断线**：`keyword` 对 `code.bg` ≥ 4.5:1；`label` 对 `header_bg` ≥ 4.5:1；`text` 对 `code.bg` ≥ 12:1。
- **禁止**：六套主题共用一套近似灰；用深色头主题的浅橙去画行内关键字；为保住深色头让标签低于门槛。

### G16 对比度不够就调明度

- **触发**：任何前景/背景配色。
- **执行**：正文/墨色对纸底 ≥ 7:1（WCAG AAA，**以六套内置主题实际取值为准**）；代码 text 对 code.bg ≥ 12:1；关键字、注释、语言标签对各自底色 ≥ 4.5:1；不足时向墨色压深，深色头上向亮色提亮。
- **判断线**：`check_themes.py` 与 `derive_palette.py --audit-themes` 都输出 ALL PASS；两者门槛一致（正文 7:1、code.text 12:1、keyword/comment/label 4.5:1）。
- **禁止**：靠加粗、放大字号、描边或浅色硬凑；把「能看见」当成「可读」。

### G17 一屏一个命名者（封面可替代文本）

- **触发**：标题、导语、章节头、卡片并置时；或封面图已含主标题/栏目/副标题。
- **执行**：每屏只保留一个主导标题层级与一个视觉焦点。**封面已经用视觉承担的知识，正文不必再用文字重复**：IR 里设 `cover_carries_title: true`（或 `decisions.cover_carries_title`），`build_article.py` 会跳过正文的 kicker / h1 / subtitle，正文从信息卡或导语开始。Markdown 存档与 HTML `<head><title>` 仍保留标题，便于回溯与后台填写。导语不重复标题主张，卡片标题不重复章节名。
- **判断线**：同一屏内没有两个同等权重的标题在争主次；封面与正文不出现同一句主标题；缩略图状态下仍能读出唯一主张。
- **禁止**：标题 + 副标题 + kicker 各说一套主张；封面写了标题、正文再原样写一遍；用多个色块同时抢焦点。

## S5 校验交付

### G18 校验 0 ERROR 才算完成
- **触发**：每次出稿。
- **执行**：`validate_article.py --expect-figures N` 校验；再截首屏确认图片不是破图；交付 HTML、PNG、Markdown、来源说明。
- **判断线**：`valid=true`；未替换占位符 = 0；`<img` 数 = base64 图数 = 独立 PNG 数。
- **禁止**：不跑校验就交付；只看 JSON 的 `valid` 不看失败项；把破图或空白页当成品。

## 全流程

### G19 成本与合规前置

- **触发**：下载模型/权重、调用付费或积分能力、引用地域与主权表述。
- **执行**：先说明体积与消耗并取得同意；合规按规范写。
- **判断线**：用户同意记录在 `decisions`；来源、缺失片段、书面化引语、自拟标题全部显式标注。
- **禁止**：静默消耗积分；静默下载 GB 级内容；编造来源身份；把一致度说成准确率。

## 与机器校验的对应（N3）

| guardrail | 机器判定 | 落点 |
|---|---|---|
| G4 无署名占位符 | `{{...}}` = 0 | `validate_article.py` S12 |
| G10 默认不生图 | 流程默认 + `decisions.image_mode` | `ci_check.py` 报告字段（生图例外须有用户同意） |
| G13 全内联 / 白名单 | `<style`=0、`class`=0、外链=0、标签白名单 | `validate_article.py` S01–S05 |
| G15 代码框六槽位 | 六槽位字段齐备 + `keyword`/`comment` 对比度 ≥4.5 | `check_themes.py` |
| G16 对比度 | `body`/`ink` 对 `page` ≥7，`code.text`/`bg` ≥12 | `check_themes.py` + `derive_palette.py --audit-themes` |
| G18 校验 0 ERROR | `valid=true` 且 `NEEDS_DECISION` 未出现 | `ci_check.py` |
| G12b 两图间有正文 | 相邻图之间非图注中文字符 ≥40 | `validate_article.py` 的 S22 |
| G1/G2/G3、G11/G12/G17 | 流程/人工卡点，不能机器判定 | S0-B 决策 + 逐张看图；G17 的封面开关由 `build_article.py` 执行 |

**不可判定的不硬凑成 lint**：看图是否有溢出、一屏是否只有一个视觉焦点，仍由人看。

## 首次使用

### G20 Python 解释器先判定，必要时才问

- **触发**：每个新环境第一次使用本 skill。
- **执行**：跑 `resolve_python.py --json`。记住的路径、可用的系统默认 `python`/`python3`、或检测到 `uv` 等环境管理器，都直接用且**不询问**；三者皆无才在 S0 主动询问用户 Python 运行地址，并用 `--set` 记住。
- **判断线**：`needs_ask=false` 时全程没有解释器提问；`needs_ask=true` 时必有用户给出的路径且已写入 `~/.skillshub/python.json`。
- **禁止**：不问就猜一个路径；把路径写进仓库或分发包；每次运行都重复询问。
