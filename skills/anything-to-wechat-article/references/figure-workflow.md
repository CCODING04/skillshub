# 插图工作流（默认代码画图，不用生图工具）

## 一句话指令

> 基于给定正文，先提炼出这张图唯一要回答的问题，再选最贴切的图示类型（对比／流程／清单／封面）；只呈现原文确有的事实与关系，不替读者下结论、不把讲者的个人选择写成标准答案；用浅底深字、两色以内、固定画布与全内联样式画出中文信息图，渲染成 2 倍图后逐张看图修正溢出与压字再交付；主题、口径与是否采用由人决定，模型只给选项和依据，不代选。

**口径（N4）：默认不生图，一律用现有画图方式——HTML/CSS 版式经无头浏览器 2× 渲染成 PNG，中文标注交给 DOM。** 只有用户明确指定 AI 插画时才可改变；此时先说明积分消耗并取得同意。任何情况下都不用生图模型渲染中文标注。

## 五层（顺序不可倒）

| 层 | 要做什么 | 反例 |
|---|---|---|
| 1 内容层 | 只画原文确有的事实与关系；讲者的个人选择标注「他选择」，不画成标准答案 | 把「我会删掉这三项」画成「正确答案」 |
| 2 结构层 | 先定这张图唯一要回答的问题，再选图型 | 先挑好看的模板再往里塞内容 |
| 3 视觉层 | 浅底深字、两色以内、字号层级、留白 | 渐变、阴影、多色、装饰性插画 |
| 4 工程层 | 固定画布、全内联样式、无外链、中文用系统字体栈 | 依赖网络字体或外部 CSS |
| 5 校验层 | 逐张看图 → 修溢出／压字 → 重渲染 → 复看 | 「差不多就行」直接入稿 |

## 问题 → 图型

| 这张图要回答什么 | 图型 | 典型画面 |
|---|---|---|
| 这篇文章讲什么、读它的理由 | 封面 | 标题 + 元数据 + 一个抽象主体符号 |
| 几个选项里哪个是我要的 | 清单／可划除卡片 | 四张功能卡片，划掉三项、标注保留项、底部注明无标准答案 |
| 两种做法差在哪 | 双栏对比 | 左右并排，同一组步骤对照 |
| 全场脉络与下一步动作 | 路线图／步骤卡 | 宫格总览 + 行动卡 |
| 先后顺序或因果 | 流程箭头 | 线性 3–5 步，单向箭头 |

## 工程实现

1. 从 `assets/figure_types/` 复制 `cover.html` / `comparison.html` / `checklist.html` / `roadmap.html` 中合适的骨架，改文案与数据，存为 `figures/fig1.html` 等；尺寸与清单参考同目录的 `manifest.example.json`。
2. 写 `figures/manifest.json`：
   ```json
   {"figures":[
     {"html":"fig1.html","out":"fig1.png","width":1080,"height":460},
     {"html":"fig2.html","out":"fig2.png","width":1080,"height":600}
   ]}
   ```
3. 运行 `python scripts/render_figures.py --manifest figures/manifest.json --dir figures`。
   内部用 Chrome/Edge 无头模式：`--headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2 --window-size=W,H --screenshot=out.png file:///…/figN.html`。
4. `html,body` 固定宽高、`overflow:hidden`；所有 fill／color 显式写死，不依赖 class 或 CSS 变量。

## 校验闭环（不能省）

逐张用图像查看工具检查：文字是否完整、有无截断／乱码、卡片是否溢出容器、副标题是否被压、底部结论是否显示。

常见失败与修法：步骤文字溢出压住结论 → 改容器高度、缩小内边距与箭头间距；标题换行压住副标题 → 缩短标题、降低字号、加高卡片。改完重渲染并复看。

最后把 PNG 交给 `build_article.py` 做 base64 内嵌，同时保留独立 PNG。

## 图注

每张图配一行小字，写「这张图在回答什么」，而不是「示意图」。例：`图 2 ｜ 两种交互隐喻：交出请求等成品，还是看得见、改得动`。
